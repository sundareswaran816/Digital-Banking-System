# 🏦 Digital Banking System

## 📌 Overview
The **Digital Banking System** is a **Spring Boot Microservices** project developed as a college capstone project. It simulates the core functionalities of a banking application by separating different banking operations into independent microservices.

---

## 🚀 Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- REST API
- H2 Database
- Maven
- Spring Cloud API Gateway
- IntelliJ IDEA
- Postman

---

## 📁 Project Structure

```text
Digital-Banking-System
│
├── accountservice
├── customerservice
├── loanservice
├── transactionservice
└── ApiGateWay
```

---

## 🛠️ Modules

### 👤 Customer Service
- Add Customer
- View Customer
- Update Customer
- Delete Customer

### 💳 Account Service
- Create Account
- View Account
- Update Account
- Delete Account

### 💰 Transaction Service
- Deposit Money
- Withdraw Money
- Transfer Money

### 🏦 Loan Service
- Apply for Loan
- View Loan Details

### 🌐 API Gateway
- Routes client requests to the appropriate microservice.
